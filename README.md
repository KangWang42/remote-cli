## 它解决什么问题

让 Claude Code 或 Codex 跑一个长任务，它中途常常停下来问一句“是否允许”，或者做完了等你说下一步。你不在电脑前，任务就停在那里。

Remote CLI 把电脑上的终端原样带到手机上：

- **任务等你时，手机上点一下就继续。** 提问的原文和“允许 / 拒绝”直接出现在列表的卡片上，不用进终端。
- **做完了通知你。** 开启任务提醒后，有任务等你确认或做完，手机收到一条通知。
- **随时接着说。** 打开 App 就是刚才的画面，输入下一句，或者换一个对话继续。

它不是另一个云端 AI，也不替你保管账号：跑的是你电脑上已经装好的 `claude`、`codex` 和命令行，用的是你电脑上的文件、配置和登录状态。

### 和别的办法比

| | Remote CLI | 手机上的 SSH 客户端 | 远程桌面 |
| --- | --- | --- | --- |
| 人在外面连家里或公司的电脑 | 一键隧道或中转，不用公网 IP 和端口映射 | 通常要自己解决公网地址、端口映射或内网穿透 | 常见的远控软件要注册账号，经过厂商的服务器 |
| 锁屏、换网络以后 | 任务不受影响，重新打开接着原来的画面 | 连接一断，前台任务跟着结束，除非另配 tmux 之类的工具 | 会话还在，但要重新连 |
| 知道哪个任务在等你 | 列表按状态排序，可以直接回答，做完有通知 | 要逐个连进去看 | 要盯着屏幕 |
| 在手机上操作 | 为触屏做的终端页和按键行 | 取决于客户端 | 整个桌面缩在手机里，点按和输入都费劲 |
| 接着电脑上已有的 Claude Code、Codex 对话 | 列出来点开就继续 | 要自己记会话、敲恢复命令 | 可以，但操作同上 |

## 三步上手

几分钟就能用上。先在 [Releases](../../releases/latest) 下载 `RemoteCli-Setup-x.y.z.exe`（电脑）和 `RemoteCli-Android.apk`（手机）。

### ① 电脑：安装，添加项目文件夹

运行安装程序，装完自动打开主窗口。在“项目”页点“添加文件夹”，或者把平时写代码的文件夹拖进窗口。手机只能在这里列出的文件夹里开终端。

<p align="center"><img src="docs/images/windows-projects.png" alt="电脑端：项目文件夹" width="62%"></p>

### ② 电脑：选一种连接方式

在“连接”页上方选。状态变绿、出现二维码，就可以连了。

| 你的情况 | 选 | 说明 |
| --- | --- | --- |
| 手机和电脑在同一个 Wi-Fi | **局域网** | 最快，什么都不用配。第一次 Windows 防火墙询问时选“允许” |
| 人在外面，没有服务器 | **公网隧道** | 点“下载隧道程序”，几秒后得到一个 https 地址，不用注册账号 |
| 想要固定地址，以后不用再扫码 | **中转** | 选择框里有公共中转时点一下就能用；有自己的服务器时[一条命令装一个](docs/SELF_HOSTING.md)，延迟更低 |

拿不准就先选“局域网”试一遍，之后随时可以换。换连接方式不会结束正在运行的终端。

<p align="center"><img src="docs/images/windows.png" alt="电脑端：连接方式和二维码" width="62%"></p>

### ③ 手机：扫码

安装并打开 App，点“扫码添加电脑”，对准电脑窗口里的二维码。连上以后：

1. 点一个项目，选“新建 Claude Code”“新建 Codex”或命令行，终端就开起来了；也可以从“历史对话”里点一个接着聊。
2. 回到工作台，所有任务都在“进行中”里。等你确认的那一条，直接在卡片上点“允许”或“拒绝”。
3. 想在离开 App 后收到通知，在工作台最下面打开“任务提醒”。

### Linux 电脑

```bash
curl -fsSL https://raw.githubusercontent.com/KangWang42/remote-cli/main/agent-linux/install.sh | bash
```

在要被手机使用的那台 Linux 上运行这一行，等它在终端里显示二维码，用手机 App 扫它。不需要域名、账号和 root：公网地址由 Cloudflare 的临时隧道提供，程序装在你自己的用户目录里。需要 Python 3.9 及以上和 systemd。项目文件夹可以连上后在手机里添加。有自己的域名、只在家里的网络使用、卸载和更新，见 [Linux 电脑端](docs/LINUX.md)。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 真实终端 | 手机上看到的就是电脑上 `claude`、`codex` 或 shell 的画面，可以输入、按键、翻看 |
| 接着电脑上的对话 | 列出 Claude Code 和 Codex 保存的对话，点开就继续；电脑上正开着的，先看内容再决定要不要接到手机上 |
| 手机和电脑共用终端 | 同一个终端在手机和电脑上是同一个画面，谁输入都行，不用来回交接 |
| 状态一目了然 | 等你确认、已完成、正在执行、等待输入各有一种颜色 |
| 不用进终端就能回答 | 程序问“是否允许”时，提问原文和“允许 / 拒绝”直接出现在列表的卡片上 |
| 任务提醒 | 开启后，离开 App 时有任务等你确认或做完，手机会收到一条通知；平时通知栏里没有常驻的通知 |
| 工作台管理 | 进行中与历史终端分开，直接结束终端，按电脑和项目展开或收起；同一段对话只列一次 |
| 三种连接方式 | 局域网直连、公网隧道、中转（公共的或自己的，可以保存多个）。换连接方式时终端不会结束，手机重新扫码后还是同一批 |
| 终端连接状态 | 显示连接方式、断线重连次数和最近测得的中转延迟 |
| 顺滑的拖动 | 翻看终端时画面按像素跟着手指走，松手后带惯性滑行；Claude Code 和 Codex 自己滚动的界面也一样 |
| 查看文件 | 在手机上翻看项目文件夹：代码、Markdown、笔记本、表格、PDF、图片，也可以保存到手机；Word 和 PowerPoint 带格式显示 |
| 六套外观 | 两套明亮、四套深色，文字大小和行距可调；电脑端窗口用同样的六套，默认与 App 一致 |
| 软件内更新 | 电脑端和 App 都会检查新版本，下载并校验后安装；也可以从手机上让电脑端更新 |

## 安全

这个工具让拿到地址和密码的人在你的电脑上执行命令，请当作 SSH 密码一样对待。

- 密码由程序随机生成，在电脑上用 Windows 的 DPAPI 加密保存；中转只保存登录令牌的哈希。
- 同一地址连续输错 6 次密码会被锁 15 分钟，所有地址合计也有上限。
- 局域网直连走的是不加密的 http，只在可信的网络里用。在外面请用公网隧道或自己的 https 中转。
- 公网隧道的地址是随机的，但能被知道地址的人访问到登录页，保护它的只有密码。
- 手机只能在你添加的项目文件夹里启动终端，但终端启动后和你坐在电脑前一样，可以访问整台电脑。
- 查看文件只能读你添加的项目文件夹里面的内容；文件夹里指向别处的链接不会被打开。文件内容经中转传给手机，中转不保存。
- 中转和电脑端都不记录终端的输入输出到日志；中转把最近的终端画面保存在它的数据目录里，供手机重连后恢复显示。

发现安全问题请通过 GitHub 的私密漏洞报告提交。

## 已知限制

- 带窗口、自带中转和公网通道的电脑端只有 Windows。Linux 是后台服务形式，功能与 Windows 电脑端有所不同，见 [Linux 电脑端](docs/LINUX.md)。macOS 的电脑端还没有写。
- 没有 iOS App。
- 界面只有中文。
- 任务提醒要在工作台里手动开启，由系统大约每分钟唤醒 App 查看一次，不是服务器推送，所以通知会比实际晚几十秒到一分钟，手机深度休眠时更久；有些手机限制后台活动，需要在系统里允许它自启动或后台运行。
- 使用公共中转时，终端的输入和输出会经过那台中转服务器，它的运营者在技术上能够看到；不希望如此时请用局域网直连、公网隧道或自己的中转。
- 你在电脑上自己开的命令行窗口，手机只能看它的对话内容，不能接着那个窗口用；要在手机上继续，得先结束它。想两边共用，请从手机或电脑端“活动”页新建终端。Codex 的“另开一份继续”依赖支持 `fork` 的 Codex CLI（核对版本 0.161.0）。
- 经公网时，按键到回显的延迟主要是网络往返（手机 → 中转 → 电脑 → 中转 → 手机），局域网直连最快。
- 同时最多 8 个终端。
- 查看文件是只读的，不能在手机上编辑、上传或删除。Word 和 PowerPoint 的预览是手机页面自己排的：不分页，PowerPoint 的母版样式和图表可能走样。旧格式的 doc、ppt 不能预览，但可以保存到手机后用别的应用打开。
